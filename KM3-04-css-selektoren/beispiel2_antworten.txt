Selbsttest im Prüfungsformat


2a 
Richtige Aussagen: 1, 2 und 4.

Aussage 3 ist falsch, weil :nth-child(2) das zweite Kind insgesamt auswählt, während :nth-of-type(2) das zweite Element desselben Typs auswählt. 

--
2b 
1. Alle Links, deren Ziel auf .pdf endet:
   a[href$=".pdf"]

2. Alle Absätze außer denen mit der Klasse hinweis:
   p:not(.hinweis)

3. Das erste li in jeder ul:
   ul > li:first-child

4. Jedes Element, das ein img enthält:
   :has(img)

5. Das Häkchen, das direkt vor einem label steht:
   input[type="checkbox"]:checked + labell

--
2c 
p:nth-child(1) wählt nur einen Absatz aus, wenn dieser das erste Kind seines Elternelements ist. Steht zum Beispiel eine Überschrift davor, funktioniert die Regel nicht.

Richtig:
p:first-of-type {
    font-weight: bold;
}

Damit wird der erste Absatz jedes Elternelements fett formatiert,
auch wenn davor eine Überschrift steht.
